# VLSI Design

This repository contains the projects, assignments, and lab materials completed for the VLSI Design course. The coursework is divided into two main parts: practical analog integrated circuit (IC) design and a comprehensive literature review on advanced semiconductor technologies.

## 📁 Repository Structure

The repository is organized into three main directories:

### 1. `pmos ldo`
This folder contains the implementation of a **Low-Dropout (LDO) Regulator** utilizing a **PMOS pass element**. 
* **Environment:** Designed and simulated using **Cadence Virtuoso**.
* **Details:** This represents the hands-on design portion of the course. The folder includes the circuit schematics, testbenches, and simulation states. Please refer to the included project report for a detailed breakdown of the design methodology, performance specifications, and final simulation results.

### 2. `literature` (Bibliography)
The theoretical part of the course focused on modern sub-micron transistor architectures. This folder contains a detailed synopsis of four academic research articles.
* **Topics Covered:** **FinFET** (Fin Field-Effect Transistor) and **FD-SOI** (Fully Depleted Silicon-On-Insulator) technologies.
* **Contents:** Contains the compiled literature review, reference PDFs, and presentation materials evaluating the comparative performance and structural evolution of these advanced nodes.

### 3. `LAB2026`
This directory contains a base **Cadence Virtuoso library** provided at the beginning of the course. 
* **Purpose:** It served as a sandbox tutorial environment to learn the Virtuoso software ecosystem, experiment with basic analog blocks (like Current Mirrors and VCO cells), and get comfortable with running ADE XL simulations. 
* *Note: This folder is kept primarily for personal reference, archiving, and software familiarization.*

## 🛠️ Tools & Technologies
* **EDA Software:** Cadence Virtuoso (Schematic Editor, ADE XL / Assembler)
* **Design Domains:** Analog IC Design, Power Management (LDO Regulators)
* **Theoretical Concepts:** Advanced Node Semiconductor Devices (FinFET, FD-SOI, GAA)
